# CrossTalk documentation

CrossTalk studies the language, evidence and visual design of the defense software engineering journal. Study edition 0.1.0 covers 281 retained issue PDFs and 9,660 physical pages. The Python tooling is version 0.5.0. [Preprint and companion data](https://doi.org/10.5281/zenodo.24297224)

| Task | Guide |
| --- | --- |
| Install and verify the tooling | [Getting started](guides/getting-started.md) |
| Acquire, extract, search or measure a corpus | [Corpus workflow](guides/corpus.md) |
| Build the study PDF from its published inputs | [Manuscript reproduction](reproduction/manuscript.md) |
| Inspect the study, its methods and sources | [Manuscript](manuscript/) and [input manifest](reproduction/template-render-inputs-v0.1.0.csv) |
| Cite or reuse material | [Citation](../CITATION.cff) and [license scope](license-scope.md) |

Use GitHub issues for reproducible bugs, documentation corrections and historical source leads. Include the command, source locator or figure involved and the evidence needed to reproduce the observation. Changes should preserve provenance, source distinctions and coverage limits, and include the relevant verification results. [Issue tracker](https://github.com/docxology/CrossTalk-study/issues)
